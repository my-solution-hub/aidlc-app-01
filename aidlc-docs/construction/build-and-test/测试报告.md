## 六、测试环境配置

### 前置条件
```bash
# 1. Docker Desktop 运行中
# 2. MySQL 容器
docker run -d --name mysql84 -p 3306:3306 -e MYSQL_ROOT_PASSWORD=Il0veaws mysql:8.4

# 3. Redis 容器
docker run -d --name redis-test -p 6379:6379 redis:7-alpine

# 4. 创建数据库
docker exec mysql84 mysql -uroot -pIl0veaws -e "
  CREATE DATABASE IF NOT EXISTS awsome_shop_auth;
  CREATE DATABASE IF NOT EXISTS awsome_shop_product;
  CREATE DATABASE IF NOT EXISTS awsome_shop_points;
  CREATE DATABASE IF NOT EXISTS awsome_shop_order;
"
```

### 运行命令
```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/amazon-corretto-21.jdk/Contents/Home

# 单元测试（无需外部依赖）
cd awsome-shop-auth-service && mvn test -pl bootstrap -Dtest="UserDomainServiceImplTest,PointRemoteClientTest"
cd awsome-shop-points-service && mvn test -pl bootstrap -Dtest="PointAccountDomainServiceImplTest,PointDistributionSchedulerTest"
cd awsome-shop-order-service && mvn test -pl bootstrap -Dtest="ExchangeRecordApplicationServiceImplTest"
cd awsome-shop-product-service && mvn test -pl bootstrap -Dtest="ProductApplicationServiceImplTest"
cd awsome-shop-gateway-service && mvn test -pl bootstrap -Dtest="RateLimitingConfigTest"

# 集成测试（需要 MySQL + Redis 运行）
cd awsome-shop-auth-service && mvn test -pl bootstrap -Dtest="AuthServiceIntegrationTest"
cd awsome-shop-points-service && mvn test -pl bootstrap -Dtest="PointAccountAtomicDeductIntegrationTest"
cd awsome-shop-order-service && mvn test -pl bootstrap -Dtest="IdempotencyAndRateLimitIntegrationTest"
cd awsome-shop-product-service && mvn test -pl bootstrap -Dtest="ProductServiceIntegrationTest"
```

### 后续建议
1. **CI/CD 集成**: 将测试加入 GitHub Actions，使用 Testcontainers 自动管理容器
2. **Testcontainers 升级**: 当前版本 (1.19.3) 与 Docker Desktop v29 不兼容，升级到 1.20+ 后可去除本地 Docker 手动管理
3. **E2E 测试**: docker-compose 启动全部服务后，用 REST-assured 做端到端验证
4. **性能测试**: 使用 JMH 或 Gatling 对并发扣减、兑换 Saga 做压力测试
