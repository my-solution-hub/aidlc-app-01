## API 契约（前端实际调用，已确认）
| 服务 | 端点 | 用途 |
|---|---|---|
| auth | POST /auth/api/v1/public/auth/login | 登录 |
| auth | POST /auth/api/v1/public/auth/logout | 登出 |
| auth | POST /api/v1/public/auth/user/list | 用户分页 |
| product | POST /product/api/v1/public/product/list | 商品列表 |
| product | POST /product/api/v1/public/product/create | 创建商品 |
| product | POST /product/api/v1/public/category/list | 类目树 |

| order | POST /order/api/v1/admin/exchange-record/get | 兑换详情 |
| order | POST /order/api/v1/admin/exchange-record/stats | 兑换统计 |
