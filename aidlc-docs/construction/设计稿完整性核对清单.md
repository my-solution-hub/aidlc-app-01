## 使用说明

- 每项缺失带 `[ ]` 复选框，补齐并验证后改为 `[x]`，并在「核对人/日期」列签注。
- 优先级：🔴 P0（数据断链/半截实现）· 🟠 P1（体验关键、低成本）· 🟡 P2（远期/需产品决策，多数被 MVP 明确排除）。
- "MVP 范围"列标注该项在 `requirements.md` 中的归属：✅ 在范围 / 🟡 部分相关 / ❌ 明确排除或未提及。

## 一、总体覆盖现状

| 维度 | 设计稿 | 已实现 | 覆盖度 |
|------|--------|--------|--------|
| Web 员工端页面 | 9 | 9（Login/Register/ShopHome/ProductDetail/Confirm/Success/Orders/OrderDetail/Points） | ✅ 页面齐全 |
| Web 管理端页面 | 11 + 10 弹窗 | 10 页面 + 弹窗 | 🟡 缺 Team 部门页 |

**结论**：核心链路（登录 → 浏览 → 搜索 → 详情 → 兑换 → 扣分扣库存 → 订单 → 历史）端到端可用；认证含账号锁定、Saga 库存补偿齐全。缺失集中在设计稿的**进阶/远期功能**，多数被需求文档 §4 列为 Out of Scope（物流、地址、通知、报表）。

## 五、已实现且与设计稿一致（核对通过项，无需补充）

> 列出以避免重复排查。

- ✅ 认证：注册 / 登录 / 登出 / token 校验 / 刷新 / 改密码 / 当前用户，**含账号锁定**（连续失败 → 锁定）
- ✅ 商品：列表 / 搜索 / 分类筛选 / 详情 / 推荐（销量 TOP10）/ 创建 / 编辑 / 删除 / 上下架 / 批量导入 / 单图上传
- ✅ 分类：树形结构 / 增删改 / 启用禁用 / 强确认删除
- ✅ 积分：余额 / 流水 / 管理端用户积分列表 / 手动调整 / 规则 CRUD / 发放配置 / 自动发放触发
- ✅ 订单：员工下单（校验余额+库存）/ 我的订单 / 订单详情 / 管理端列表 / 统计 / 状态更新 / 物流单号 / **Saga 库存补偿**
- ✅ 管理端：Dashboard 4 KPI 卡 + 最近兑换 · 用户管理（增删改/启停/角色/CSV 导出）· 兑换记录（筛选/统计/CSV 导出）
- ✅ 兑换确认显示当前余额与兑换后余额（前端计算）
